# Professional Portfolio

Portfolio of Venkata Sai Varun Mooraboina for AIML-500 Machine Learning Fundamentals at Indiana Wesleyan University.

Pages:

- index.html: About Me and My Value Proposition
- artifact-1.html: Artifact 1, A Timeline of Artificial Intelligence
- artifact-2.html: Artifact 2, Interview Prep Coach chatbot

Supporting files:

- style.css: shared styles ("research notebook" design, light and dark themes)
- script.js: theme toggle and on-page section highlighting
- assets/AI_Timeline_Deck.pdf: the timeline deck exported from Keynote
- assets/AI_Lab_Documentation.pdf: the AI Lab documentation exported to PDF

The site is plain HTML and CSS with no build step, published with GitHub Pages.
